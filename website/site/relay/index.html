Deploy your own relay.

A relay joins your phone to your computer when they have no direct path. This page creates a small DigitalOcean droplet in each region you choose, running the signed relay image with a Let's Encrypt certificate and no DNS to set up.

It sees only end-to-end encrypted bytes and keeps nothing on disk. Read Relays for how it works.

1 A DigitalOcean token

In DigitalOcean, open API > Tokens and generate a token that expires soon, with Custom Scopes: droplet create and read, ssh_key read, and tag create. Or use Full Access.

It stays in this page: sent only to api.digitalocean.com, never stored, and forgotten when you close the tab. Delete it in DigitalOcean once your relays answer.

2 Regions

One droplet per region. Pick the ones near you and your computers; one is enough.

3 Options

DigitalOcean bills each droplet monthly; see its droplet pricing.

Left empty, each relay is served at IP-WITH-DASHES.sslip.io. With relay.example.org, the relay in nyc3 is nyc3.relay.example.org, and you point that name at its droplet.

SSH keys (optional)

Paste a token to choose SSH keys. Without one, reach the droplets from DigitalOcean's web console.

    Without a token

    In DigitalOcean, choose Create > Droplets, the region, Ubuntu 24.04, and a size. Under Advanced options, check Add initialization scripts, paste this, and create it. The relay answers a few minutes later at https://IP-WITH-DASHES.sslip.io, or at the domain you named.

    Then add each relay's address in Sheprd under Settings > Remote control > Relays. The page builds the droplets' user data from deploy/relay on main, as create-droplet.sh does; each droplet runs only an image whose signature it verified.
